\## About



This repository contains the practical assignments completed as part of the DevOps Lab. The assignments cover fundamental DevOps concepts and tools including Git, GitHub, Jira, Docker, and Jenkins.



The practical work demonstrates version control, collaborative development, project and issue tracking, application containerization, and Continuous Integration using commonly used DevOps tools.



\---



\## Assignments



\### TW1.1 - Git Workflow \& Collaboration



This assignment focuses on understanding Git and GitHub for version control and collaborative software development.



The practical includes:



\- Working with a GitHub repository

\- Cloning a remote repository

\- Creating and managing branches

\- Working with local and remote repositories

\- Committing changes

\- Pushing changes to GitHub

\- Viewing branch and commit history

\- Understanding collaborative Git workflows



Supporting screenshots are available in:



`TW1.1/screenshots/`



\---



\### TW1.2 - Jira Project \& Issue Tracking



This assignment focuses on using Jira for software project management and issue tracking.



The practical includes:



\- Creating a Jira project

\- Creating and managing issues

\- Working with different issue types such as Story, Task, and Bug

\- Managing issues using a Jira board

\- Moving issues through different workflow stages

\- Tracking the progress of development tasks



The workflow demonstrated is:



`TO DO → IN PROGRESS → DONE`



Supporting screenshots are available in:



`TW1.2/screenshots/`



\---



\### TW1.3 - Basic Containerization (Docker) \& Jenkins



This assignment focuses on basic application containerization using Docker and build automation using Jenkins.



\#### Docker



A simple Flask application was containerized using Docker.



The practical includes:



\- Creating a Flask application

\- Creating a Dockerfile

\- Building a Docker image

\- Running a Docker container

\- Mapping container ports

\- Verifying the running container

\- Accessing the containerized application through the browser



The Docker-related source files are included in the `TW1.3` directory.



\#### Jenkins



Jenkins was used to understand Continuous Integration and build automation.



The practical includes:



\- Creating a Jenkins Freestyle project

\- Connecting Jenkins with a Git repository

\- Executing Jenkins builds

\- Viewing Console Output

\- Creating and executing a Jenkins Pipeline

\- Working with build parameters

\- Verifying successful builds



Supporting screenshots are available in:



`TW1.3/screenshots/`
